# Descriptive Statistics 📊

## About the Project

This project performs **Descriptive Statistics using Python** on an Income and Expense dataset.

The dataset contains information about household income, expenses, family members, EMI/Rent, annual income, education, and earning members.

## Dataset

* **Rows:** 50
* **Columns:** 7
* **Dataset:** Income and Expense Data

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis Performed

* Dataset loading
* Data inspection
* Shape and column information
* Descriptive statistics
* Mean
* Standard deviation
* Minimum and maximum values
* Quartiles
* Data visualization

## Main Function Used

```python
income_df.describe()
```

This provides basic statistical information about the numerical columns.

## Objective

The main objective of this project is to understand **household income and expense data using basic descriptive statistics**.
